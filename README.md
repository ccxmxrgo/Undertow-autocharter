# UNDERTOW Autocharter pack

Download host for the optional **Autocharter pack** used by the game [UNDERTOW](https://github.com/ccxmxrgo/undertow) ("Chart a Song").

The game downloads the files from the release **autocharter-pack-v1** and checks every file against SHA-256 values built into the game before installing, so files that do not match are refused.

You do not need to download anything here by hand: open **Chart a Song** in the game and press **Download**, or use the "Autocharter Pack" folder that ships in the friend zip.

The pack contains a Python runtime, open-source libraries and model weights (see NOTICES inside the pack). It contains no music.
